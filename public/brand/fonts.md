# Typography

**Wordmark:** the "Boldflow Labs" lettering in the kit is a heavy geometric sans. It is closest to **Plus Jakarta Sans ExtraBold** (free, SIL Open Font License), with tight tracking. In every logo SVG the wordmark is converted to outlines, so no font install is needed to use the logos. It is a close match, not the original artwork.

**Brand typeface (per the kit):** Inter, weights Light to Bold - https://fonts.google.com/specimen/Inter
Use Inter for headlines, subheads and body text.
