# Boldflow Labs - Brand Assets

Recreated from "Boldflow_Labs_Brand_Identity_Kit.png". The logo mark was redrawn as vector; the wordmark is Plus Jakarta Sans ExtraBold (closest match to the kit lettering) converted to outlines.

## Folders
- logo/svg - horizontal, stacked, icon-only in full-color, reverse (for dark), white, black. Transparent, scalable.
- logo/png - transparent PNGs (512 / 1024 / 2048 px wide; icon 256 / 512 / 1024).
- logo/on-backgrounds - logos on white, dark navy and brand blue.
- icon - app icons (white, dark, brand blue, black tiles) as SVG and PNG.
- favicon - favicon.ico, favicon.svg, PNGs 16-512, apple-touch-icon, android-chrome.
- social - profile picture (square + circle), LinkedIn banner, X header, OG share image.
- colors.md / colors.json, fonts.md

## Usage rules
- Default: horizontal logo. Use stacked for square spaces, icon-only for app icons and favicons.
- On white or light backgrounds use full-color; on navy use reverse; on Electric Blue use the white version.
- Keep clear space around the logo equal to the height of the "B" cap letter in the wordmark.
- Minimum size: 120 px wide for the horizontal logo, 16 px for the icon.
- Do not stretch, recolor, rotate, add shadows or place on busy images.
